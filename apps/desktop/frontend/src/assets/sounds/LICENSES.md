# Sound licences

Every sound here was synthesised for The Bakery by `make.py` in this folder,
from sine waves, with no recorded or third-party audio. They are dedicated to
the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Run `python3 make.py` to make them again.

| File | Plays when | Source | Licence |
| ---- | ---------- | ------ | ------- |
| `task-done.wav` | a task on the open board reaches Done | `make.py`, original | CC0 1.0 |
| `letter.wav` | a letter or an event letter arrives | `make.py`, original | CC0 1.0 |
| `run-finished.wav` | a run on this machine finishes | `make.py`, original | CC0 1.0 |
| `run-failed.wav` | a run on this machine fails | `make.py`, original | CC0 1.0 |
